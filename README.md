# Open Media Downloader

一款基于 Chrome Manifest V3 的浏览器媒体下载扩展，可识别网页中的视频、音频及流媒体资源，并在本地完成下载与音视频合并。

当前版本：**1.0.0**

## 功能特性

- 自动识别网页中的视频和音频资源
- 支持选择不同分辨率与媒体格式
- 支持单独下载音频并转换为 MP3
- 支持 DASH 音视频分离流的下载与合并
- 支持 HLS/M3U8、DASH/MPD 和普通 HTTP 媒体
- 支持弹窗和浏览器侧边栏两种操作方式
- 支持下载历史、桌面通知和并发下载设置
- 支持自定义文件名和下载子目录
- 支持浅色、深色及跟随系统主题
- 提供多语言界面

## 安装方法

本仓库目前提供的是可直接加载的浏览器扩展文件。

1. 下载或克隆本仓库：

   ```bash
   git clone https://github.com/justlovemaki/Open-Media-Downloader.git
   ```

2. 打开 Chrome 或其他 Chromium 浏览器的扩展管理页面：

   ```text
   chrome://extensions/
   ```

3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库根目录。

更新代码后，请在扩展管理页面点击“重新加载”。

## 使用方法

1. 打开包含视频或音频的网页。
2. 播放媒体几秒钟，以便扩展捕获媒体请求。
3. 点击浏览器工具栏中的 Open Media Downloader 图标。
4. 在识别列表中选择需要的资源和分辨率。
5. 选择下载视频、另存为或仅下载音频。

如果没有识别到资源，可以刷新页面后重新播放媒体。

## 使用须知

- 扩展无法下载受 DRM 保护的内容。
- 部分网站要求登录后才能获取媒体地址。
- 媒体地址可能具有时效性，识别后应尽快下载。
- 下载结果取决于网站提供的清晰度、编码和音轨。
- 请仅下载你有权保存和使用的内容，并遵守网站条款及当地法律。

## 权限说明

扩展需要访问标签页、下载、网络请求和网页脚本等权限，用于：

- 检测网页及播放器中的媒体资源
- 获取媒体请求所需的请求头
- 合并分离的视频流与音频流
- 将处理完成的文件保存到浏览器下载目录
- 在弹窗或侧边栏中展示识别结果

## 项目结构

```text
├─ src/                # 语义重构后的可维护源码
├─ scripts/            # 构建和检查脚本
├─ test/               # 重构核心协议测试
├─ manifest.json       # 扩展清单
├─ content/            # 弹窗、侧边栏和界面构建产物
├─ injected/           # 网站适配器构建产物
├─ service/            # 后台 Service Worker 构建产物
├─ download_worker/    # 下载、转码与音视频合并逻辑
├─ factory/            # Worker 创建页面
├─ _locales/           # 多语言资源
└─ bitmaps/            # 扩展图标与图片资源
```

## 故障排查

### 无法识别视频

- 刷新页面并重新播放视频。
- 确认扩展已启用且拥有当前网站的访问权限。
- 尝试关闭播放器后重新打开。
- 直播或动态播放列表可能需要等待数秒才会出现。

### 音频下载失败

- 确认媒体本身包含可用音轨。
- 哔哩哔哩等网站采用音视频分离流，请使用最新版本扩展。
- 重新加载扩展并刷新视频页面后再试。

### 下载文件无法播放

- 尝试选择其他分辨率或格式。
- 在设置中切换 MP4/MKV 输出格式。
- 确认下载期间媒体地址没有过期。
